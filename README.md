AutoNova

Site de apresentação de uma loja fictícia de carros online. Projeto de portfólio para mostrar design e front-end.

O que tem no site
Página inicial com chamada principal e números de destaque
Carros disponíveis passando em duas faixas animadas
Depoimentos de clientes em colunas que sobem sem parar
Seção sobre o projeto
Botão de contato para o LinkedIn
Tecnologias
HTML, CSS e JavaScript puro
Arquivo único (autonova.html), sem instalação

Observações
Os carros, preços e depoimentos são fictícios.
Os carros são ilustrações em SVG.
Tema claro e escuro automático.
